# 试点内容审计

审计日期：2026-10-23。本文描述本地五个代表性试点组的清单，不代表已完成全课程审计或远端发布批准。

## 范围与章节划分

- 单元试点：二年级上册数学第二单元——“100 以内的加法和减法（二）”。
- 学期试点：二年级上册数学前半学期，使用正式编号单元 01～04。
- 跨年级、跨学科单元试点：三年级上册英语第一单元 “Myself”，主题是姓名、年龄和自我介绍。
- 高年级、第三学科单元试点：五年级上册语文第一单元“一花一鸟总关情”，覆盖借具体事物表达感受、依据文本线索阅读、班级公约讨论和心爱之物习作。
- 低年级单元试点：一年级上册数学第一单元“准备课”，覆盖数一数、比一比和 0 的初步认识；范围根据课程清单与课程单元元数据登记。
- 用户确认按教材章节顺序将九个正式单元尽可能等分：前半学期 01～04，后半学期 05～09。这只是项目计划边界，不表示任何学校的实际授课日历。
- 二年级数学单元 2 题池取自本单元题目及 42 道闯关专用补充题；前半学期组取自单元 01～04 及同一批补充题。
- 三年级英语单元 1 题池取自该单元 48 道现有课程题及 42 道英语闯关专用原创补充题；按课程教材清单，该册使用 TapXWorld 固定回退快照 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7`，未将回退来源称为最新版，学校是否开设该英语册尚未确认。
- 五年级语文单元 1 题池取自该单元 48 道已审现有课程题及 42 道闯关专用原创补充题；语文教材清单使用同一固定 TapXWorld 回退提交 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7`，不称为最新版。
- 一年级数学单元 1 题池由 46 道不重复的现有课程题和 44 道闯关专用原创补充题组成；两道在不同难度间重复的原课程算式题不进入闯关题池，原课程活动保持不变。
- 没有修改现有学习任务的题目来扩充闯关题池。

## 知识点映射与覆盖

清单按题目保存知识点 ID。试点映射函数根据来源单元、题干、算式和交互内容推导知识点；一年级数学的原创题使用逐题登记的知识点；五年级语文还使用班级公约高阶任务的路径规则。测试会把全部 496 条清单记录与映射函数比对，再使用生产组卷器及固定种子为每个已登记任务组卷，并检查所需知识点是否覆盖。

最初的映射曾把单元级全部知识点赋给该单元的每道题，这可能造成虚假覆盖；审计前已改为逐题映射。二年级上册数学单元 1 的两道高阶题涉及安全规划测量活动，额外标记为 `measurement-activity-planning`；该标签不计入单元核心知识点覆盖。

高阶综合要求针对整份组装后的试卷，而不是声称每道题都同时考查两个概念。每份高阶任务至少覆盖两个核心知识点，组卷测试会核实这一点。

映射函数是确定性的内容分类器和测试判据，只能提供结构性保障，不能独立证明所有标签在教学上均准确；后续学科审查可能调整题库清单。

## 就绪状态与审计限制

本地测试中的五个试点组均通过当前题库清单和组卷门禁。质量命令为每个已发布任务运行 100 个固定种子，5 组共 25 个任务、2500 次模拟全部成功；最新报告有 0 个阻断项、0 个精确重复组和 226 条相似题提示。一年级新增的 44 道补充题没有命中相似题对。相似题提示仍需结合教学语义判断，不等同于重复错误。这表示题池通过已实现的结构、兼容性、指纹、候选数量和标签覆盖检查；这不是对全部内容质量的发布签字，不替代必要的教学审核，也不证明整个闯关系统已就绪。

本次审计未覆盖：后半学期和期末综合任务、三年级英语其他单元、其他年级或学科、全课程覆盖、独立教学审核、跨浏览器及跨标签页故障审查、存储配额/驱逐、通用数据迁移、备份/恢复及 GitHub 持续集成/部署证据。
