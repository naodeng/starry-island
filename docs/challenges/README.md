## 已确认基线

1. 闯关是独立模式；保留现有学习 Task、学习进度和交互方式。
2. Local First、静态部署、复用 React/Vite，不要求首版引入后端或在线 AI 出题服务。
3. REQ-001～REQ-085 是产品决策来源；最新明确决策优先。REQ-080 覆盖 REQ-037 中“内容指纹变化即自动撤销审核”的规则。
4. 采用 TDD，按基础引擎、代表性试点、完整课程覆盖分阶段交付。
5. 正式发布需通过题库质量、评分正确性、数据一致性、学习回归和必要的教学内容审核。

## 当前交付边界

- 本地工作区实现了独立闯关入口、试点组卷与首答计分、IndexedDB 自动保存/恢复/完成、进度与结果摘要，以及单元测试和浏览器恢复流程。
- 85 项仍是产品决策索引，不是 85 项均已实现的声明。逐项状态与证据见[需求追踪矩阵](REQUIREMENTS_TRACEABILITY.md)。
- 正式发布仍需完成更广泛课程覆盖、全量题目审核、跨标签页与存储故障专项验收、备份/迁移/恢复能力及发布流程。不能将试点状态当作全产品发布批准。
- 仓库事实与本地验证证据按日期记录；本地构建或测试不代表 GitHub CI、远端合并或 Cloudflare Pages 部署已通过。
