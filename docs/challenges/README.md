## 已确认基线

1. 闯关是独立模式；保留现有学习任务、学习进度和交互方式。
2. 遵循本地优先和静态部署原则，复用 React/Vite；首版不要求引入后端或在线 AI 出题服务。
3. REQ-001～REQ-085 是产品决策来源，最新明确决策优先。REQ-080 覆盖 REQ-037 中“内容指纹变化即自动撤销审核”的规则。
4. 采用 TDD，按基础引擎、代表性试点、完整课程覆盖分阶段交付。
5. 正式发布需通过题库质量、评分正确性、数据一致性、学习回归测试及必要的教学内容审核。

## 当前交付边界

- 已有本地实现包括独立闯关入口、试点组卷与首答计分、IndexedDB 自动保存/恢复/完成、进度与结果摘要，以及跨标签页冲突保护和 Web Locks 接管。
- 已提交的错题本只记录答错题的快照、答错次数、最近答错时间和连续答对次数，不保存完整作答历史；结果页的薄弱知识点入口只导航至现有学习任务，不更改课程进度。
- 闯关成长统计从闯关进度记录即时汇总完成次数、曾通过任务、已点亮徽章和已登记组进度；不保存完整历史，也不推算连续学习天数。该功能仅覆盖当前登记的试点路线，并已通过浅色/深色、对比度、窄屏、键盘焦点和减少动态效果检查。
- 本机备份支持导出版本化 JSON、SHA-256 校验、导入预览与 IndexedDB 原子安全合并；主题和语音偏好可选携带，并在闯关记录合并成功后由用户明确选择是否应用；不会读取或写入现有课程进度。合并规则和剩余恢复能力见[本地数据模型](DATA_MODEL.md)。
- 本机数据支持分级清除、24 小时单一恢复点和安全合并恢复；清除与恢复均使用 IndexedDB 事务，具体限制见[本地数据模型](DATA_MODEL.md)。
- 题库质量 CLI、全课程覆盖盘点和课程源素材盘点命令已实现。质量命令默认针对清单中每个已发布任务运行 100 个固定种子；覆盖盘点核对全部正式单元、108 个学期阶段组及 1,810 个任务；源素材盘点按难度统计 254 个正式单元中可复用的兼容课程活动、精确重复和最低题量缺口，并输出中文 Markdown 与机器 JSON。当前挑战清单登记 5/254 个正式单元组、1/108 个学期阶段组和 30/1,810 个任务；课程源活动盘点发现每个单元各难度均未达到 30 条唯一素材最低量，且这些素材未经闯关审核。V1.0 标签会启用严格覆盖门禁。完整题库内容、独立教学审核和远端 Actions 结果仍待完成。
- 闯关中心新增手动诊断下载入口，报告按字段白名单只含版本、浏览器能力和记录数量；主要存储错误会分类成儿童可理解的恢复提示。REQ-070/071 已通过当前本地单测、浏览器和生产构建验证，仍未推送或进入正式发布。
- 85 项仍是产品决策索引，不代表 85 项均已实现。逐项状态与证据见[需求追踪矩阵](REQUIREMENTS_TRACEABILITY.md)。
- 正式发布仍需更广泛的课程覆盖、全量题目审核、存储故障专项验收、备份/迁移/恢复能力和发布流程。不能将试点状态当作全产品发布批准。
- 仓库事实与本地验证证据均按日期记录。本地构建或测试不代表 GitHub 持续集成（CI）、远端合并或 Cloudflare Pages 部署已通过。

## 全课程覆盖盘点

- 执行 `npm run challenge:coverage` 可生成正式单元、学期阶段组和任务覆盖报告；`--report-dir <目录>` 可指定报告目录。
- 执行 `npm run challenge:source-audit` 可生成全课程活动素材盘点；它只统计当前题型兼容性、同一正式单元同一难度内的精确重复和距最低素材量的差额，不为素材自动打上审核状态。
- 常规盘点模式会列出缺失项但不阻断渐进式开发。执行 `npm run challenge:coverage -- --require-complete` 时，缺少任一正式单元组、学期阶段组、已发布状态或规定的任务难度结构都会返回失败。
- Quality 工作流在分支和拉取请求上记录非阻断缺口；推送 `v1.*` 标签时运行严格覆盖门禁。工作流配置已在本地核对，远端 Actions 尚未运行。
- 覆盖报告只证明课程目录与挑战组登记关系完整，不证明题目内容、答案或教学审核合格；仍须通过 `npm run challenge:quality` 和逐题内容审核。
