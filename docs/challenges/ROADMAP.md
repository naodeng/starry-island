## 基础引擎：可运行的最小功能切片（已在本地提交）

- 新增独立的 `/challenges` 中心、组和任务路由，并与现有学习流程分离、按需加载。
- 登记一年级上册数学第一至第四单元，二年级上册数学第二单元与前半学期，三年级上册英语第一单元 “Myself” 和五年级上册语文第一单元，共八个试点组。根据用户确认，二年级上册数学九个正式单元按教材章节顺序尽可能等分；这不代表学校实际授课日历。
- 提供声明式题库清单、逐题知识点标签、发布校验、稳定内容指纹、重复检查和确定性组卷；题量或覆盖不够时拒绝组卷。
- 支持首答计分、挑战中不显示提示/重试、完成后查看讲解、IndexedDB 保存/恢复、丢弃、原子更新进度、最近三次题目跟踪、星级和任务进度。
- 现有学习存储和交互保持独立；浏览器流程检查学习进度未改变。
- 跨标签页冲突保护与 Web Locks 接管已提交至 `b68c582`。

题量：七个单元组各有 90 道候选题（每个难度 30 道）；前半学期组 226 道候选题（基础 75、进阶 75、高阶 76）。八组共有 856 个组内候选位置、766 条唯一清单记录。三年级英语和五年级语文单元 1 每档各 30 题，由 16 道现有课程题和 14 道原创补充题组成；一年级数学第一单元每档由 46 道不重复原课程题和 44 道原创补充题组成；第二、第四单元每档由 16 道原课程题和 14 道原创补充题组成；第三单元基础、进阶、高阶每档由 16/15/14 道去重课程题与 14/15/16 道原创补充题组成。第四单元不同难度的现有课程活动有相同题干模板，质量报告会提示；未修改课程 Task。逐题审核边界见[试点内容审计](pilot-content-audit.md)及其链接的六份补充题审校台账。

## 试点阶段：跨年级与跨学科验证（进行中）

先选择低（1～2）、中（3～4）、高（5～6）年级代表，覆盖三门学科、单元/学期挑战、难度层级和交互题型。当前八组试点覆盖一年级数学、二年级数学、三年级英语和五年级语文，代表了低、中、高年级、语文/数学/英语及单元/学期挑战；这不等于完整课程覆盖。当前本地试点还包含结果页薄弱知识点汇总、到现有学习任务的复习入口、按本机保存记录汇总的成长视图、按需朗读当前题干，以及按年级切换的题干密度规则。后续还需通过更广的真实课程内容完成无障碍审查、失败恢复、备份/迁移和题目编写工具验证；朗读设备听感优化暂缓。

错题本首版已加入当前登记的八个试点组：保存错题快照、答错次数与最近答错时间；同一道题在两次不同的后续完成挑战中连续答对后标记为已掌握，再答错会重置。它尚未覆盖其他未登记的年级、学科或课程，也不代表全课程发布就绪。最新本地单测、端到端回归和构建证据见[测试方案](TEST_STRATEGY.md)。

课程扩展与闯关可靠性可以分别推进。现有本地可靠性改动包含共享 IndexedDB 修订号校验、模糊写入时比对完整快照，以及 Web Locks 等待/重新读取/接管；不支持 Web Locks 的浏览器依赖修订号校验。版本化备份、安全合并、24 小时恢复点、版本 1～3 数据库升级、异常记录隔离、已知格式的逐条预览恢复/按需原始导出，以及已载入挑战的断网完成已在本地实现并有测试。配额错误下的待保存答案保护、安全重试与返回/重新读取确认也已实现，但还没有验证真实配额耗尽和空间释放。静态应用没有 Service Worker 或强制重载；用户手动刷新时从 IndexedDB 恢复已确认进度。对未知或损坏记录的推测性自动修复不受支持；离线冷启动/刷新、浏览器进程崩溃恢复、真实配额恢复和浏览器驱逐处理仍未完成。

试点阶段退出条件：通过内容审核、跨标签页故障测试、无障碍交互审查及发布门禁演练。

- 发布报告、完整题目生命周期和审核流程、变更日志、发布说明、自动化和人工内容门禁。GitHub 问题反馈与题目修正表单已加入本地工作区，需进入默认分支后才可在线使用；手动诊断与安全清除/恢复已在当前本地切片实现，但尚需扩展到完整课程发布流程。

覆盖盘点由 `npm run challenge:coverage` 生成；普通模式用于展示缺口，`--require-complete` 严格检查课程目录映射、全部组已发布、每组五个任务及两基础/两进阶/一高阶结构。Quality 工作流已配置在 `v1.*` 标签触发该门禁。通过覆盖门禁不替代逐题质量门禁或教学审核。

课程源素材盘点由 `npm run challenge:source-audit` 生成；它只读载入正式课程活动，排除不兼容的测量题，统计支持题型、同一单元同一难度内的精确重复和每单元每难度的素材缺口。它不会自动将课程活动登记为已审核闯关题。

退出条件：没有已发布挑战违反强制质量门禁；端到端数据安全测试通过；质量报告和发布说明已准备好。
