# GitHub 问题反馈表单

仓库提供两类供维护者和成人协作者使用的 GitHub 问题反馈表单：

- `.github/ISSUE_TEMPLATE/bug-report.yml`：报告功能故障、数据异常或显示问题。
- `.github/ISSUE_TEMPLATE/question-correction.yml`：提交题目答案、讲解、表达或难度修正建议。
- `.github/ISSUE_TEMPLATE/config.yml`：关闭空白问题条目，引导提交者选择合适表单。

## 使用边界

提交的问题条目可能对公众可见。不要填写学生姓名、学校、班级、联系方式、成绩或可识别个人的信息，也不要附带包含这些信息的截图。题目修正应提供教材定位信息或公开来源链接，不要粘贴大段教材原文或上传扫描页。诊断信息不会自动添加；如需排查，提交者可以在应用内手动导出脱敏报告后自行决定是否附上。

题目修正报告只是待审核建议，不会自动发布或修改题库。维护者应核对答案、教学依据、年龄适配、难度与影响任务，再按现有内容门禁进行修改和发布。表单文件进入默认分支并且仓库启用 GitHub 问题跟踪功能后，才会显示在新建问题页面；本地文件存在不代表远端功能已经启用。
