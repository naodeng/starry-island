## 本轮发现与处理

- 将此前未逐题列入修复记录的 **555 个运行时差异 ID** 逐一对应到源文件改动和最终题面，其中语文 407 个、数学 148 个；每题均补入台账及具体原因。这些数字表示发生变化的题目 ID，**不表示新增缺陷数**。
- 数学 148 个差异包括 48 道同伴选择题提示语序澄清、15 道仅学加减单元中的干扰项/提示范围修正、6 道计时条件澄清和 79 道其他内容修复或术语完善。G4T2 数学 U7 高阶任务一第3题和 G5T2 数学 U6 高阶任务一第6题只作编辑性澄清，未计作数学错误；G3T1 数学 U8 的6题规范分数读法，也未计作算术或逻辑错误。
- 修复新发现的共享数学匹配题转换问题：一年级和三年级数学中进阶/高阶两个任务的第3题，共 160 道运行时题目，现保留原匹配指令并核对正确选项键与解释；三年级下册复式统计表题补入完整表格数据。逐题范围记入一年级与三年级数学台账，回归测试覆盖全部 160 题。
- 英语 4,512 题全部复核；相较基线有内容变化的 1,386 个题目 ID 中，1,294 个有精确题目 ID 修复记录，另 92 个由共享生成器修复范围覆盖。直接改写课程 `index.ts` 的 39 个模块涉及 736 个变化 ID，现已逐题补齐准确 ID 和改写原因，未发现漏登；其余 650 个变化位于没有直接改写课程文件的模块，按共享生成器最终呈现逐题复核并登记影响范围。三年级上册 Review-02 中不自然的干扰项“我有一个生日”已改成“我的生日在六月”，并把三个受影响题目 ID 明确写入台账。
- 确认六年级上册英语 Review-01 仍在课程注册表中，运行时包含 48 题，台账覆盖 48/48。
- 复核结论已补充到共享生成器和台账规则：运行时变化不能直接视为缺陷数量；模板改动要核对最终题面和全部影响 ID，编辑性澄清与错误修复分开记录。
