# 课程内容分层审核规则

新增或修改课程时，按“学期 → 单元 → 任务 → 题目”顺序审核。上层范围未通过时，不开始下层放行；任一层存在未解决的正确性或教材匹配问题，该课程不得标记为已核验或开放。本规则适用于所有年级、学科、册次和后续接入的文章式、主题式或项目式学习内容。

## 一、学期审核：确认课程边界和教材版本

进入单元审核前，先确认整册课程属于哪一本书、哪一个学期和哪个课程范围。

- 核对年级、学期、学科、课程条目总表和册次目录，确认新增内容归属正确、没有漏册、错册或重复登记。
- 核对 `src/content/textbooks.ts`、相应教材清单和课程注册表中的版本 ID、来源类型、固定快照、核验状态及版本差异。一个册次只使用一套已裁定的来源，不把不同版次的目录、术语和单元顺序拼在一起。
- 找不到完整、可核实的新版学生书或目录时，按项目裁定使用固定回退来源；明确记录回退状态、准确路径或链接及已知差异，不把回退快照称为最新版。
- 确认册次是否覆盖目标内容、前后学期衔接是否合理。复习内容只能引用已经学过并在册次范围内登记的知识。
- 检查新增 ID 是否唯一，学期内课程顺序和课程数量是否与已核实的目录一致。学校是否开设某学科未获证实时，应保留“未确认”状态。

**放行条件：** 课程范围、教材版本、来源和内容边界均可追溯；不存在版次混用或未经证实的目录推断。

## 二、单元审核：确认目录、主题和来源范围

逐个课程条目对照同一册次的教材目录、单元正文和登记信息。

- 核对正式单元编号、条目类型、名称、目录顺序以及 `unit`、`review`、`integrated-practice`、`theme` 分类；未编号主题组应登记为 `theme`，不得冒称教材正式编号单元或计入单元成就。
- 核对 `sourceTopics` 是否覆盖本单元应教主题，同时排除其他册次、未教知识和与本单元无关的词汇、算式、故事或情境。
- 对复习条目，标清覆盖的前置单元，并核实每个复习知识点都确实已在此前出现；综合实践可跨主题，但每项活动都须能对应已登记的教材主题或数学/语言实践目标。
- 检查一个单元内的题目覆盖主要主题，不因题目数量多而误认为主题覆盖完整。对必学词表、拼音表、数位范围、课文类型、操作活动或语法表达，按教材目录逐项列出覆盖证据。
- 不复制教材原文、扫描页、插图或大段受保护内容；题目、情境、解释和反馈使用原创表达。

**放行条件：** 目录映射和 `sourceTopics` 有教材证据；单元的题目范围完整且没有越界。

## 三、任务审核：确认学习目标、顺序和难度

审查基础档的全部任务（至少两个）以及进阶、高阶各两个任务；每个任务的目标要能从题目中观察和验证。当前“课程目录与内容编写规范”规定基础档任务至少两个，故基础档不限定为恰好两个。

| 版本 | 适合的认知活动 | 不合格情形 |
| --- | --- | --- |
| 基础 | 直接辨认、一个知识点、一步计算、带提示的操作 | 引入未教知识、隐藏条件、陷阱或多个合理答案 |
| 进阶 | 在熟悉的新情境迁移已学方法，或组合两个相关知识点并核对 | 只换数字、姓名、物品或题干表面措辞；重复基础做法但没有增加思考要求 |
| 高阶 | 在已学范围内独立规划步骤、比较方案、发现错误、证明分类或解释依据 | 引入高年级知识、冷僻规则或不必要的复杂阅读；把猜测、竞速当作高阶 |

- 同一难度档的任务须有不同的可观察目标或应用情境；进阶和高阶两个任务还须考查不同的迁移或推理动作。
- 同一课程、同一难度档的任意两个任务都要互相比较；任务不得直接复用完整题目。重复检查需忽略题目 ID 和选择题选项顺序，并比较题干、提示、解释、正确答案及题型内容；只共享答案标签或选项集合不能单独判为重复，须结合题目考查目标复核。
- 任务顺序符合认知要求；先提供必要的辨认或方法练习，再安排应用、检查或解释。不能只靠任务标题宣称难度不同。
- 同一题目位置比较三档时，检查实际考查的对象、提问方式、认知动作和答案证据。至少一半题位应体现可说明的目标或操作差异；仅换数值、角色、选项顺序和同义题干不计为差异。
- 题型应服务学习目标。配对、分类、排序、计算、阅读或表达等形式不能为凑类型而添加，也不能让答题操作和目标知识脱节。

**放行条件：** 基础档全部任务及进阶、高阶各两个任务的目标、前置知识、顺序和难度均清楚；各档及同档任务之间有实质差异，且没有越年级内容。

## 四、题目审核：逐题确认题意和答案

逐一检查所有版本、任务和场次中的每道题，不只抽查新题或随机样本。

- **题意：** 题干、配图/材料（如有）、题目指令完整；信息足够且没有隐藏条件、含糊指代、歧义分类标准或不自然语言。
- **答案：** 对照题目独立求解并核对答案键。选择题必须只有一个可判定的正确选项且选项互异；排序和分类键完整；分类标准准确，同类内容只列一次相同标准；配对项事实正确，互动形式允许该对应关系。
- **提示与解释：** 与题目条件和正确答案一致；不泄漏错误结论，也不能用题干没有提供的信息解释答案。
- **教材与年龄：** 题目属于对应单元和任务范围；词汇、句长、阅读量、单位、数字范围及生活情境符合年级。熟悉情境不应要求学生依赖地区习俗或家庭条件。
- **题目质量：** 同一任务不得出现答案相同但实质重复的题目，同档两个任务之间也不得复用完整题目。题型和情境应围绕主题变化；复习可以再次检验同一知识，但须更换目标动作、材料或任务情境。仅换数字、角色、选项顺序、题目 ID 或同义措辞，不算有实质差异。
- **学科复核：** 数学逐式重算并检查单位、数值范围、边界、余数、日期和情境关系；英语核对拼写、大小写、词义、语法、标点和交流目的；语文核对字词、音节/声调、题意、解释和年级术语。
- **标识：** 核对题目 ID 全局唯一，答案键引用实际选项或项目；换题后同步更新相关答案、解释、测试和题目台账。

重复配对答案标签不能只按字符串自动判错。若两个不同问题的正确关系确实共享同一答案，须确认内容事实成立，且学生界面仍能清楚地完成全部连线；否则改成无歧义的配对或其他题型。

### 从历史修复提炼的逐题复核规则

- **每题信息自足：** 学生应能只凭当前题卡及其明确展示的共用材料作答。引用前题、前题答案或未展示的上下文时，须把必需条件在本题重述；不能假设学生记得前题内容。
- **事实有依据：** 题目若要求判断某个事实或“证据是否充分”，必须在题面中提供可识别的来源、文本线索、观察记录或数据。把“通常”“大家都”等泛化说法写进题干，不等于给出了证据；若考查假设情境，应明确标成假设。
- **顺序确实唯一：** 排序题的条件必须排除其他同样合理的顺序。若两个步骤可以互换，应接受所有符合条件的顺序，或补充可验证的先后条件、改成比较步骤依据等明确任务；不能只凭答案键指定唯一顺序。
- **答案逐项映射：** 对分类、配对、排序和多选题，逐项核对内容与答案键实际引用的索引/选项/卡片，再核提示和解释。题型结构完整、索引有效或标签看起来合理，都不能证明映射正确。
- **核对最终呈现：** 对生成器或模板题检查学生实际看到的完整文本及答案交互，包括拼接后的语序、标点、指令和题型是否一致。修复模板后按完整题目 ID 范围确认所有受影响实例，并加运行时回归检查。
- **重新推导而非照抄：** 数学答案从题目给定的数据独立计算；语文判断回到题面文本或可核实语言知识；英语逐句核词义、语法和真实交流意图。随后确认解释展示了足以推出答案的依据，且没有引入题面外的情境假设。
- **区分变更与缺陷：** 运行时题目和基线不同，只能证明内容发生变化，不能直接计作一个缺陷。共享生成器改动须记录实际影响范围并复读最终呈现；逐题修复按准确 ID 和原因登记。只改善措辞或术语的编辑性澄清应明确标注，不混入错误数量。

**放行条件：** 每道题均有唯一、准确且可复核的答案；题意、提示、解释、教材范围和难度全部通过。

## 自动检查、AI 主审与人工复核记录

自动检查用于发现结构风险，不能替代内容判断。按当前项目决定，找不到对应教育者时以 AI 逐题主审为主；AI 必须直接读取每题最终题面，独立求解，并核对教材依据、任务目标、答案、选项/交互键、提示、解释、年龄适配和难度。对不能从已登记教材来源或题面证据确定的事实，标记“待核实”，不得猜测后判为通过。

至少运行适用的课程布局/注册表测试、全量生成题结构扫描、答案引用与重复选项检查、算式复算、同任务重复检查和跨难度对比；按项目规范再运行测试、覆盖率、E2E、构建和差异空白检查。自动扫描通过、生成题数达到预期、或单元/任务标题相符，都不能单独证明题目正确或课程匹配。

如另有独立教育者参与，应分开记录其姓名、资质声明、复核范围和日期；没有教育者参与时将教育者复核数记为 0，不填写虚构身份，也不把 AI 主审表述为教师签核。AI 主审为当前主要审校方式，不代表 AI 具有教师资质；存在未解决的答案错误、范围越界、教材证据缺失或任务难度问题时，仍须标记“未完成/待核实”，不得放行。

每个审核记录至少包含：

```text
课程 ID | 教材版本/来源 | 单元或主题依据 | 题目总数/已审数 | 答案 | 表述/年龄 | 教材匹配 | 任务/难度 | 修复记录 | 复核范围与证据 | 状态
```

发现问题时，在“修复记录”逐项记录受影响的完整题目 ID、错误原因和修复内容；一行一个修复项。生成器修复可使用精确题目范围简写，但必须能无歧义地展开到实际受影响的完整 ID，并说明模板原因、覆盖数；台账校验应逐一确认展开后的 ID 存在。若修复影响某课程全部 48 题，可使用 `<课程 ID>/{basic|advanced|high}/task-{01|02}/session-01/question-{01..08}`。未修复的题不得伪装成修复记录。

“复核范围与证据”单独记录审核日期、AI 已审题数、完整题目 ID 范围、教材来源和自动检查依据；如有教育者复核，则另列已复核数量、范围与证据。每个课程条目都应有复核范围，即使没有缺陷或修复；没有修复时“修复记录”保留“无”。尚未逐题审完、教材证据无法核实、或仍有未解决正确性/匹配问题时，状态使用“未完成/待核实”，不得标为“完成”。

## 新内容放行门槛

1. 学期审核先通过，确定唯一版本和来源；
2. 单元审核通过，目录和主题范围有证据；
3. 基础档全部任务（至少两个）以及进阶、高阶各两个任务均通过目标、顺序、前置知识和难度审核；
4. 全部生成题目逐题审核完毕，答案、解释和题型键无未解决错误；
5. 检查跨档差异、同任务重复、教材主题覆盖和所有题目 ID；
6. 更新对应年级的审核台账并运行项目规定的验证命令。

任何正确答案错误、范围越界、错误归单元或任务难度不合适的问题都属于阻断项；修复并复核所有受影响题目后，才可放行。
