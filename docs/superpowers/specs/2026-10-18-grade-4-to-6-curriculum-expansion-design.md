# 四至六年级上下学期课程扩充设计

## 目标与范围

本阶段沿用现有课程选择器，为四、五、六年级上下学期登记语文、数学、英语共 18 册、153 个教材目录条目，并记录可追溯的来源与版本边界。新增条目标记为“筹备中”，不生成可玩的课次，也不计入学习进度或成就。英语延续站内人民教育出版社“一年级起点”序列，学校开课状态仍记为未确认。

完整课程仍需后续逐条编写原创题目并完成审校。只有教材目录、课次内容和逐题审校记录齐全后，才可将条目开放。

## 教材来源

- 先核对人教社公开的最新版学生用书及完整目录；配套练习、教师用书、旧版电子书或新版教材简介不能代替完整学生书目录。
- 若完整新版学生书目录无法公开核实，使用仓库既定 TapXWorld 固定提交 `5a80345f2043ba6f8db8d7be9cf3db82725ff1f7`，记录每册精确 PDF 路径、人教社新版证据及可确认的差异。回退教材不称为最新版；未知版次、印次和 ISBN 留空。
- 语文、数学和英语目录不得混合不同系列或版次。所有练习、解释、情境和反馈均为原创，不复制教材原文、插图或 PDF。

## 课程数据与质量要求

- 登记目录数据并沿用现有课程注册表、进度 manifest 和成就规则；筹备条目不创建课程单元、场次或题目 ID。
- 每个正式单元包含基础、进阶、高阶三档；每档两个目标不同的任务，每项任务一场 20 分钟场次、恰好 8 道题。复习与综合实践按目录分类且不计正式单元成就。
- 每个课程条目记录可追溯的 `sourceTopics`、教材版本 ID 和稳定全局唯一 ID；数学计算逐式复核，英语词汇、拼写、语法逐项复核，语文题意及主题逐题复核。
- 审校台账逐条覆盖全部新增题目。未完成逐题核对的条目不得标记为“完成”或开放。

## 验收标准

1. 18 册教材来源、回退原因、已知差异和可核实目录均有清单记录；18 个教材版本在元数据中唯一注册。
2. 153 个目录条目与来源元数据及课程选择器注册一致，全部保持“筹备中”，不进入课程单元、进度或成就。
3. 后续课程编写阶段再验收任务数量、场次时长、每场题量、答案引用和逐题审校台账；本阶段不声称这些内容已完成。
4. 运行课程结构和来源检查、相关测试、`npm run build`、`git diff --check`；检查完整差异和工作区状态。不提交或推送。

## 实施更新（2026-10-19）

用户随后授权完成全部课程内容，原验收标准第 2、3 项的“保持筹备”阶段已结束。四至六年级 153 个条目现均接入课程目录，每项 48 题，共 7,344 题；逐题审校证据及最终验证结果记录在 [课程扩充实施计划](../plans/2026-10-18-grade-4-to-6-curriculum-expansion.md) 和 [逐题审校台账](../../curriculum/grade-4-to-6-question-review.tsv)。

教材版本仍严格使用上述固定 TapX 快照。课程作者按目录主题设计原创练习；英语核心词卡另与六册附录单元词表对照。该工作没有逐页审校所有教材正文，不将词表外拓展词宣称为教材原文；英语学校开课情况仍未确认。完整课程和版本边界见 [教材清单](../../curriculum/grade-4-to-6-textbook-inventory.md)。
