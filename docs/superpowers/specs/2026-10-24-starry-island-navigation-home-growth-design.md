# 星岛学园全局导航、首页与成长中心设计

状态：供用户评审的架构规格。用户已认可首页预览方向和完整设计规格；本文定义实施边界，不代表产品代码已经修改或实施。

## 1. 目标与成功标准

随着课程、闯关和本地数据管理功能增加，建立稳定、清晰的全局导航和学习入口，让学生可以从首页继续课程、分别查看学习与闯关进度、回顾近期学习、进入闯关；同时将备份恢复移到设置，并在统一成长入口中查看课程成就和闯关成长。

成功标准：

- 任意主要页面都能通过共同导航前往首页、课程、闯关、成长、错题和设置。
- 页眉左侧是 Logo 与“星岛学园”，菜单按钮在最右侧；导航抽屉默认关闭，打开时浮在页面上方。
- 首页按顺序呈现“继续学习、当前进度、最近学习记录、闯关入口”。
- 课程和闯关分别计算、分别存储，展示可以统一，学习进度不可混为一谈。
- 用户可从设置进入独立的备份与恢复页面；闯关中心专注于挑战内容。
- 成长入口保留课程星图/宇宙头衔和现有闯关徽章/进度。
- 闯关按需播放已有本地答题音效；播放失败或静音不影响作答和保存。
- 原有学习 Task、学习进度、课程深链和交互方式通过回归验证。

## 2. 已确认决策与工程实现建议

### 2.1 已确认决策

- 用户选择方案 B：把首页改为学习任务仪表盘，课程目录作为可从导航访问的独立页面。
- 页眉左侧放品牌标识和项目名称，右侧放菜单按钮。导航默认收起；展开时是浮层，不挤压主内容。
- 设置入口放在导航内；备份与恢复从闯关主页面移到设置中的独立页面。
- 首页展示：1) 继续学习；2) 当前进度；3) 最近学习记录；4) 闯关入口。
- 保持本地优先、静态部署和现有 React/Vite 技术栈，不增加后端；兼容浅/深色、键盘、屏幕阅读器和减少动态效果。
- 延续仓库的 Animal Island UI 视觉系统和现有课程学习行为。

### 2.2 本文的默认工程方案

以下是为形成可实施方案而作出的建议，不是已验证的实现事实：

- 首页使用路径 /；课程目录移到 /courses；设置使用 /settings 和 /settings/backup；成长统一到 /growth。
- /achievements 继续打开成长中心的“学习星图”，/challenges/growth 继续打开“闯关成长”视图，确保旧链接兼容。
- “继续学习”按有效学习起点和注册课程顺序定位最早的未完成场次。现有应用不持久化关闭页面后的临时答案，因此此入口继续课程位置，但不承诺恢复场内答案。
- 最近学习记录用有界的本地完成事件保存；旧进度无时间戳，不补造历史时间。应用新的学习起点只调整进度计算，不伪造学习活动，也不删除已发生的近期活动。
- 成长中心整合已有的成就与进度，不在本次 UI 工作中增加未经定义的徽章门槛、连胜、排名或惩罚规则。
- 闯关正确/错误提示复用已有本地音频，在结果持久化成功后播放；“进行中”使用视觉状态，不新增音效。

## 3. 非目标与排除项

- 不改课程内容、顺序、开放范围、评分规则或题库。
- 不重做课程答题器，不更改学习进度含义，也不把挑战数据写入课程学习存储。
- 不增加账号、云同步、遥测、网络语音、外部音频或服务端数据库。
- 不在首页复制完整课程目录，不把备份、诊断或隔离记录放回闯关中心首屏。
- 不伪造旧完成日期，不用聚合进度的更新时间冒充逐次挑战记录。
- 不采用排行榜、公开竞争、连续打卡压力或惩罚性失败反馈。
- 本规格评审阶段不修改产品代码、不提交或推送实现。

## 4. 当前仓库事实

以下事实来自规格起草时的只读检查；实施前应按当时仓库状态复核：

- src/App.tsx 管理路由显示、学习进度和全局点击提示；当前 AppFrame 没有全局页眉/导航。
- src/app/router.ts 将 / 解析为课程目录，/achievements 为课程成就，/challenges/growth 为闯关成长。
- 课程目录在 src/components/catalog/CourseCatalog.tsx；设置由 src/components/settings/SettingsDialog.tsx 以弹窗承载，含主题、语音、学习起点和成就入口。
- src/challenges/ui/ChallengeCenter.tsx 把备份导入导出、诊断、隔离记录管理与挑战组列表放在同一页面。
- 课程成就由 src/components/achievements/ 与 src/achievements/ 提供；挑战成长由 src/challenges/ui/ChallengeGrowth.tsx 和 src/challenges/domain/growth.ts 提供。
- src/storage/progress.ts 当前为 schema 3，保存完成场次 ID 和可选学习起点，不保存完成时间。
- 闯关数据存放在独立 IndexedDB。闯关进度含聚合完成次数和 updatedAt；成长汇总提供已完成尝试数、通过任务数、徽章数和分组进度。
- src/App.tsx 当前对挑战页面设置 data-sound-silent；src/challenges/ui/ChallengeRunner.tsx 未调用 playCue。已有声音由 src/sound/soundCues.ts 和 SoundProvider 提供，包括正确、错误、连对、完成和交互声。
- 首页与课程目录通过路由懒加载；课程清单与挑战题库有独立模块。首页需要轻量清单元数据和挑战聚合进度，不需要首屏加载课程题目或闯关题库。
- 项目要求过程文档使用中文；页面兼容主题、键盘、可见焦点、语义标签和 prefers-reduced-motion，并保护既有学习体验。

## 5. 方案选择

### 方案 A：保留课程目录为首页，只添加页眉菜单

改动较少，但挑战、成长、最近记录和数据管理仍是分散入口，首页无法直接回答“接下来做什么”。

### 方案 B：任务首页加右上角浮层导航（已选）

首页聚焦继续学习与进度，课程目录仍从导航访问。品牌左对齐、菜单按钮右对齐，菜单以抽屉浮在内容上方。用户已通过预览认可该方向。

## 6. 全局页眉与导航

### 6.1 页眉

- 所有主要页面共享页眉。左侧展示 Logo 与“星岛学园”，点击品牌返回首页。
- 右侧显示菜单按钮，窄屏下触控目标清楚。
- 页眉不放备份入口；课程/任务页面原有面包屑可继续作为主体内导航。

### 6.2 抽屉

- 默认收起。菜单打开后带遮罩、浮在内容上方；桌面从右侧滑入，窄屏适配视口，不推动主内容。
- 导航顺序：首页、课程、闯关、成长、错题；底部以分隔线放设置。
- 选择入口、点击遮罩/关闭按钮、按 Escape 都关闭抽屉；浏览器前进后退后抽屉不遗留打开。
- 打开时焦点进入抽屉。优先使用项目已安装且类型声明支持的抽屉/对话框原语，并验证焦点陷阱；否则显式实现语义与焦点管理。
- 通过菜单入口导航到新页面时，遵循应用现有的路由标题聚焦行为，将焦点交给新页面主标题；按 Escape、遮罩或关闭按钮留在原页时，焦点返回菜单按钮。
- 菜单按钮提供中文可访问名称和 aria-expanded；当前入口有 aria-current 或等效标识。
- 动画尊重 prefers-reduced-motion；当前页面与选中状态不可只靠颜色表达。

### 6.3 路由建议

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | / | 学习任务仪表盘 |
| 课程目录 | /courses | 目录主体移出首页；现有课程单元深链不变 |
| 闯关中心 | /challenges | 聚焦挑战入口 |
| 成长中心 | /growth | 成长概览与各域成就 |
| 错题 | /challenges/wrong-questions | 保持现有路径 |
| 设置 | /settings | 偏好、学习起点及数据管理入口 |
| 备份与恢复 | /settings/backup | 独立的数据管理页 |

兼容要求：/achievements 打开“学习星图”，/challenges/growth 打开“闯关成长”。旧链接不得变成死链或误开另一个成长域；新导航使用 /growth。

课程目录迁移到 /courses 后，课程页内所有“返回课程目录”面包屑和按钮改为进入 /courses；品牌标识始终返回新的首页 /。课程单元、任务和场次深链保持原路径不变。课程目录中原有的挑战入口可以保留。

## 7. 首页内容

首页按确认顺序展示四区。桌面可用主次栏，但读屏和窄屏顺序不变，不能隐藏任一区域。

### 7.1 继续学习

- 作为主卡片和主要操作。
- 有未完成课程时，以基础版场次作为默认学习主线，按已核实、已开放课程清单的年级、学期、学科、单元、任务和场次顺序，找到最早未完成的基础版场次；显示课程位置和“继续学习”。
- 选择目标时复用 getEffectiveCompletedSessionIds；不把未开放或教材尚未核实的课程当作可继续目标。使用清单元数据定位单元，再按需加载对应课程模块，确认场次所属任务后生成现有路由器接受的有效场次链接。
- 若全部已开放课程的基础版场次均完成，主操作改为“浏览课程”，由学生自行选择进阶或高阶任务；不自动替学生选择难度。
- 当前仓库没有已确认的最后进入位置字段；首版不新增此类偏好，也不从最近完成记录推断学生偏好的难度。
- 点击后进入该场次或所属任务的有效继续位置。不得声称恢复关闭页面后未保存的临时答案。
- 无进度时指向注册序列中的首个可用场次；全部完成时改为“浏览课程”；没有可用课程时引导到课程目录。

### 7.2 当前进度

- 分别呈现“课程学习”和“闯关挑战”两张进度卡。
- 课程侧复用已有有效完成场次、单元点亮和宇宙头衔算法，不更改学习起点规则。
- 闯关侧复用既有成长汇总中的尝试数、通过任务和徽章。只有存在稳定分母时才显示比例，否则仅显示计数。
- 首页先展示课程入口，不等待闯关 IndexedDB。闯关摘要异步加载；加载中或不可用时不阻塞首页和课程入口。
- 读取挑战摘要时不得导入 ChallengePage、完整 pilotManifest 或题库内容。完整 pilotManifest 当前约 560 KB，包含大量题目元数据；成长摘要应使用不含问题 ID/题目元数据的轻量组索引，并由测试或质量门禁验证其与正式组定义一致。
- 不把两域相加成一个百分比、等级或分数；两张卡分别前往各自详情。

### 7.3 最近学习记录

- 显示最多 3 条真实课程场次完成事件，包括课程位置和本地完成时间，并提供对应课程链接。
- 建议把课程进度从 schema 3 升至 schema 4，增加有界 recentCompletions：每项为 { sessionId, completedAt }，最多保存最近 20 条，按时间倒序显示。
- schema 1/2/3 迁移须保留完成 ID 和学习起点，不能补造时间。迁移后新完成或重复完成场次才记真实活动；活动记录不得改变完成 ID 的唯一性和课程完成计算。
- 时间以完成时刻生成并保存为可排序 ISO 时间，展示时转为设备本地时间。
- 只有实际完成场次时才追加事件；设置新学习起点产生的假定已完成场次不计入近期学习。更改学习起点保留历史事件，但不改变现有的进度替换规则。
- 空状态说明完成学习后会显示新记录。迁移/导入时刻不得伪装成完成时刻。
- 挑战活动不混入“最近学习记录”；挑战域的活动归成长中心。

### 7.4 闯关入口

- 独立卡片说明这是课程学习之外的练习，并进入 /challenges。
- 可展示已有挑战摘要，但数据只来自闯关存储，且不与课程学习进度相互读写。
- 视觉层级不能与“继续学习”主操作争抢。

## 8. 成长中心

统一容器提供“成长概览、学习星图、闯关成长”三个视图。

- 学习星图复用现有宇宙头衔、星区探索和课程完成记录；规则仍由 src/achievements/ 决定。
- 闯关成长复用现有徽章、通过任务和分组进度；规则仍由 src/challenges/domain/growth.ts 决定。
- 概览并列显示两域摘要，另展示有可靠时间依据的近期成长事件；不合并两域计数。
- 第一版的过程里程碑只使用已有可证明数据：完成场次/单元、现有头衔、挑战任务通过和既有徽章。
- 课程时间线用第 7.3 节新增的本地完成事件。挑战活动只有在确认仓库可读到真实尝试事件及其时间后才能进入时间线。
- 不能把任务聚合 updatedAt 包装成每次挑战的时间记录。如无挑战事件源，展示当前挑战汇总和徽章，不展示猜测时间线；新增长期挑战历史属于独立需求。
- 鼓励式呈现，不加入排名、连续打卡或失败惩罚；未解锁状态不羞辱学生。

## 9. 设置与备份恢复

### 9.1 设置

独立 /settings 页面保留现有设置：跟随系统/浅色/深色主题、语音和交互音效开关、学习起点，以及进入备份与恢复的清晰入口。偏好本地保存，不增加云同步。移入学习起点设置时，保留现有“应用后会替换当前进度记录”的明确提示和保存结果反馈；不得弱化其数据影响说明。

### 9.2 数据管理页

将 ChallengeCenter 中现有的数据管理界面移到 /settings/backup，尽量复用现有状态机、仓库和领域逻辑，而不是另写一套流程：

- 闯关备份导出、选择文件、导入预览、安全合并和导入结果；
- 脱敏诊断信息手动导出；
- 恢复点管理；
- 隔离记录查看/导出及已设计的安全恢复能力；
- 隐私说明和存储故障提示。

移出后，闯关中心只保留挑战导航和内容。既有备份语义保持：只包含闯关数据；主题和语音偏好仅在用户主动选择时导出；导入预览单独列出偏好且默认不应用；仅闯关数据成功导入后才可应用所选偏好；课程进度和最近学习记录不进入闯关备份。

## 10. 闯关声音反馈

- 挑战页当前的 data-sound-silent 只用于屏蔽 AppFrame 的全局交互点击音，不会阻止 ChallengeRunner 直接调用 playCue。保留该隔离并由 ChallengeRunner 在持久化确认后直接播放结果音，避免点击音与答题结果音叠加。
- 仅在答案已确认且成功持久化后，播放相应的现有正确/错误本地声音；连续正确与任务完成音按现有声音反馈规则处理，同一结果不可重复播放。
- 保存失败、配额阻塞、未保存或结果不确定时不播放答题成功/失败声。
- 完成提示只在结果持久化和任务完成确认后播放一次；重复渲染、返回页面或读取历史不得重播。
- 进行中、暂存答案和保存中状态使用文本、图标或进度表示，不新增“进行中”声音文件或网络语音。
- 使用既有语音/声音开关，关闭后闯关提示音保持静音；浏览器 API、音频资源或播放失败不得阻碍答题、保存、评分和导航。
- 点击声与答案反馈声职责分开。一次作答操作不得因冒泡/重试重复播放同一反馈。

## 11. 数据迁移与一致性

- 进度迁移接受 schema 1、2、3，输出当前规范化结构；保留完成场次 ID 和学习起点，不生成旧记录时间。
- recentCompletions 最多保留 20 条；验证课程场次 ID 已注册，时间戳有效。最近列表只展示最多 3 条。
- localStorage 不可用时，保存行为遵循现有错误处理，不得声称最近记录已永久写入。
- 课程 localStorage 与闯关 IndexedDB 保持各自一致性边界；不得为了方便合并为同一进度对象。
- 数据管理页面沿用既有预览确认、安全合并、课程进度排除和隔离数据保护规则。

## 12. 无障碍、主题和响应式

- 延续 animal-island-ui 组件和 CSS 变量；使用组件前核对仓库安装版本的类型声明。
- 所有页面兼容浅色/深色主题；页眉、抽屉、卡片、状态、进度条和焦点样式保持足够对比度。
- 使用语义化链接/按钮；键盘可打开和关闭抽屉、切换成长视图、触发首页操作；焦点清晰可见。
- 路由变化后页面标题可被辅助技术识别；旧路由保留对应成长域。
- 文案面向 7–12 岁学生和陪伴者，清楚、简短、不责备；状态不只靠颜色传递。
- 尊重 prefers-reduced-motion；抽屉和卡片动效应关闭或缩短。
- 检查桌面、平板窄宽和手机视口：内容顺序、抽屉覆盖、触控目标及长中文标签换行。

## 13. 验收标准

### 导航和路由

- 每个主要页面显示共同页眉；品牌回首页；最右侧菜单打开浮层导航。
- 导航覆盖首页、课程、闯关、成长、错题、设置；备份恢复从设置的数据管理入口进入。
- 点击入口/遮罩/关闭按钮、按 Escape 均能关闭抽屉；焦点进出正确；浏览器前进后退不遗留抽屉。
- 从抽屉导航时焦点落在目标页主标题；只关闭抽屉时焦点回菜单按钮。
- /achievements 和 /challenges/growth 分别打开兼容的成长视图；已有课程单元、任务、场次深链仍有效；课程页内“返回课程目录”均回到 /courses。

### 首页、成长和数据

- 首页四区顺序正确；零进度、部分完成和全部基础版完成状态均有有效入口。
- 继续学习只依据课程进度决定目标；不把挑战进度当成课程完成，不宣称恢复未保存答案。
- 首页课程入口先于挑战摘要完成渲染；挑战 IndexedDB 延迟或失败时仍可继续学习；构建产物不因首页摘要而同步引入挑战题库。
- 两域指标分别显示且使用各自真实来源；不混成总百分比。
- schema 1/2/3 迁移不丢完成 ID 或学习起点，不回填旧时间；新活动最多保留 20 条、视图最多显示 3 条。
- 成长中心保留既有课程头衔/星图和挑战徽章/进度规则；概览没有跨域合并计分。
- 备份、诊断、恢复点、隔离记录功能在设置数据管理页可继续使用；挑战中心不再承担数据管理功能。
- 数据管理页仍实现既有冲突合并、预览确认、偏好选择和课程进度排除语义。

### 声音与整体验证

- 挑战答案成功持久化后按结果播放一次声音；失败/待重试/重复渲染时不播放结果成功提示。
- 完成提示只在任务结果持久化后播放一次；静音时无声。
- 没有音频或播放 API 失败时，答题和提交照常工作。
- 原课程学习答题、提示音、进度、题目切换与路由通过回归检查。
- 浅/深色、键盘、语义、减少动态效果、桌面与窄屏检查通过。

## 14. 验证策略

实现应遵循项目 TDD，至少覆盖：

- 课程进度 schema 3 新事件语义、首次/重复完成、最多 20 条截断、非法场次 ID/时间拒绝、schema 1/2/3 保真迁移和不回填历史时间。
- 继续学习定位：学习起点、完成进度中间有空缺、无进度、全部完成、未开放课程等边界。
- 首页挑战摘要延迟、IndexedDB 不可用或拒绝时，继续学习入口仍可操作；检查生产构建首屏依赖未同步引入完整 pilotManifest、ChallengePage 或挑战题库。
- 首页状态组件；成长概览两域指标隔离；任何活动日期都有可靠数据来源。
- 新路径和旧成长链接解析；现有课程深链保持有效。
- 抽屉键盘、Escape、遮罩、关闭返回焦点、导航后新标题焦点、ARIA 状态和窄屏行为。
- 备份导入预览/确认、冲突合并、偏好默认不应用、隔离数据处理和课程数据不进入挑战备份。
- 声音在保存成功后播放一次；拒绝/异常/待重试不播放；静音、重复提交和任务完成不双播。
- 浏览器手动检查：桌面/窄屏、浅/深色、键盘焦点、reduced motion，以及从首页完成一场课程 Task 的完整路径。

具体测试文件、命令与实施顺序由规格确认后另行编写的计划确定。

## 15. 实施前需要核实的风险

1. **继续学习路径**：默认只选基础版主线；验证课程清单、学习起点、场次 ID 与现有 loader/router 可生成稳定场次路径，不能从标题推造 URL。
2. **课程历史迁移**：升 schema 前检查所有读写、重置/清除、测试 fixture 和备份路径，确保新历史不意外进入闯关备份。
3. **挑战时间线**：确认是否有可读取的逐次完成事件。如果只有汇总，就不显示按时间排列的挑战事件，不以 updatedAt 猜测。
4. **声音时序**：定位答案持久化确认、配额错误和任务完成分支，避免点击、正确/错误、连击和完成反馈双播。
5. **数据管理页面迁移**：核实现有隔离恢复设计的实施状态和依赖，搬动 UI 时复用仓库逻辑，不复制实现。
6. **课程目录路由**：从 / 移至 /courses 时，更新所有课程内返回/面包屑目标，但保持品牌返回新首页；检查设置入口和外部链接的预期。

## 16. 建议分阶段交付

1. **数据与路由基座**：学习历史 schema/迁移，首页、课程、设置、成长、备份页面路由和旧链接兼容。
2. **导航与新首页**：共享页眉、浮层抽屉、四区首页，完成主题、窄屏、无障碍状态。
3. **成长中心整合**：复用已有课程成就和闯关成长，补充分域概览及有证据的活动。
4. **设置与数据管理迁移**：独立设置、备份恢复页面，移出挑战中心并回归现有数据流程。
5. **挑战声音和质量验证**：加入持久化后的本地声音反馈，进行端到端回归、手动 UI 检查和构建。

每阶段均需保护原课程功能；不把教学内容覆盖与 UI 改造混成难以审阅的变更。任务粒度和并行度由规格确认后的实施计划决定。

## 17. 本次复核结论

复核按现有路由、学习进度存储、课程清单、挑战仓库、页面焦点管理和提示音流程逐项比对，已消除以下实现歧义：

- 首页的挑战进度不能阻塞课程入口，且不得让挑战题库进入首页首屏依赖。
- 菜单导航到新页面时交焦点给新页面标题；留在原页关闭抽屉时才返回菜单按钮。
- 继续学习默认沿基础版主线，并只选择已核实、已开放课程；全部基础版完成后让学生自行选择进阶课程。
- 课程目录由 / 移到 /courses 后，所有旧课程页内“返回课程目录”操作进入 /courses；品牌标识仍回新首页。
- 设置学习起点保留原有替换进度的提示；进度迁移不得伪造历史活动。

独立的实现计划审阅未提出其他必须先向用户确认的问题。用户已确认设计规格，后续按本文件分成独立子计划实施。
