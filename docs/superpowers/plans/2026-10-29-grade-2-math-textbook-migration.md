# 二年级数学新教材迁移实施计划

> **执行要求：** 使用 `superpowers:executing-plans`，按任务逐项测试驱动实施。

**目标：** 按用户提供的人教版教材更新二年级上、下册数学学习与闯关内容，并将已明确批准的本机进度重置严格限制在二年级上册数学。

**架构：** 上册按六个正式单元和两项综合实践重建课程与闯关题池；下册保留现有课程 ID 和记录，仅按已审校问题修订内容及教材来源元数据。通过版本化本地迁移分别清理上册学习存储和 IndexedDB 闯关存储，迁移完成前阻止新旧内容混用。

**技术栈：** React、TypeScript、Vite、Vitest、Playwright、localStorage、IndexedDB（fake-indexeddb）。不新增服务端、课程 PDF 或新依赖。

**设计规格：** [二年级上册数学新教材迁移设计](../specs/2026-10-28-grade-2-term-1-math-textbook-migration-design.md)

## 全局约束

- 二上正式单元为“分类与整理”“1～6 的表内乘法”“1～6 的表内除法”“厘米和米”“7～9 的表内乘、除法”“复习与关联”，并含“校园小导游”“身体上的尺子”两项综合实践。
- 正式单元按教材顺序 1～3 / 4～6 划分上下半学期；实践活动分别加入对应阶段题池和期末题池，不创建正式单元成就。
- 二上旧学习和挑战记录清理必须可重试、幂等；必须保留二上其他学科、二下数学、所有其他课程、全局学习起点及隔离区原文。
- 二下继续使用原课程 ID、挑战组 ID 和学习进度；题目修订只有在学习目标不变时才沿用 ID。
- 教材来源标记为 `user-provided`，来源标识为 `urn:starry-island:textbook:isbn:<ISBN>`；版次、印次未知时保持空值；不提交 PDF、扫描页、插图或受版权保护的大段教材文本。
- 新增题目必须原创、逐题 AI 审校并标明独立教育者复核未完成；AI 结构检查不得描述为教师审核。
- 保留当前分支上所有无关修改；不提交、不推送、不合并。

## 审查重点

1. 旧版上册数据不会映射成新版成绩；部分存储迁移失败后重试不会重复清除新数据。
2. IndexedDB 迁移仅删除上册数学任务、错题和近期题目记录，且事务失败时完整回滚。
3. 仅支持当前备份快照格式；清理本地恢复点中的旧二上数学记录，恢复时不把已废止内容带回。
4. 阶段组严格按 1～3 / 4～6 正式单元组卷，综合实践仅进入指定阶段和期末题池。
5. 上册题目覆盖新教材范围且答案可独立复算；下册历史 ID 和进度不受影响。

## 文件边界

- 教材元数据与验证：`src/content/types.ts`、`src/content/textbooks.ts`、`src/content/validateCurriculum.ts` 及对应测试。
- 学习课程与目录：`src/content/grade-2/term-1/math/**`、`src/content/curriculum.ts`、`src/content/curriculumManifest.ts`、成就映射和相应测试。
- 闯关课程：`src/challenges/content/pilotManifest.ts`、JSON manifest、`pilotContent.ts`、数学补充题、知识点映射及质量/覆盖台账。
- 本机迁移：`src/storage/progress.ts`、`src/challenges/storage/repository.ts`、`src/challenges/storage/indexedDbRepository.ts`、启动路由和备份导入页面。
- 审校材料：`docs/curriculum/grade-2-textbook-inventory.md`、中文 AI 审校报告及逐题台账；教材文件只作本地来源，不复制入库。
