# 小学一至六年级课程全量审校与 PR 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 按课程内容分层审核规则核实小学一至六年级语文、数学、英语全部题目，并提交目标分支为 `main` 的 PR。

**架构：** 以课程注册表和运行时 manifest 为完整题目范围，以三个年级台账、来源清单和既有审校报告为审核证据；修复遗漏或新发现的问题后更新证据并执行全量门禁。

**技术栈：** TypeScript、Vitest、Vite、Playwright、Git、GitHub CLI。

**规格：** [课程内容分层审核规则](../../curriculum/course-content-review-rules.md)

## 全局约束

- 审核顺序为学期、单元、任务、题目；题目必须逐题核对答案、题意、提示解释、教材范围、年龄和难度。
- 数学逐式复算；英语核对词义、拼写、大小写、语法与交流目的；语文核对字词、题意和解释。
- 每个条目台账记录完整题数、已审数、各审校维度、修复 ID、审核范围和证据。
- 保留已有用户改动；只暂存本 PR 范围；创建 PR 前完成全部验证；PR 目标为 `main`。

## Review Focus

- 注册表与台账册次或条目不一致：逐项比较 1–6 年级的课程 ID、题数和状态。
- 生成器调整改变正确选项索引：遍历受影响数学题并复核实际答案键。
- 二年级台账缺少复核证据列：补录可追溯的题目 ID 范围、来源和审校依据。
- 已修复题未同步答案、解释、题型键和台账：检查各修复 ID 对应现存数据。
- PR 带入无关或构建产物：提交前按精确路径检查暂存区和差异。
