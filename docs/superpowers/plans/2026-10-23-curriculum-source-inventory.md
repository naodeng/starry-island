# 全课程闯关源素材盘点实施计划

**目标：** 在扩题前只读审计 254 个正式单元已有的课程活动，按基础、进阶、高阶汇总兼容素材数、精确重复与距每难度 30 条最低候选量的缺口。

**边界：** 复用现有课程目录和 React/Vite 环境；不修改课程 Task、学习进度或闯关发布清单，不生成题目，不把数量兼容视为已审核。测量题从候选素材统计中排除。所有过程文档用中文。

## 实施步骤

- [x] 先为去重、难度统计、测量题排除、非正式单元过滤和报告不泄露题目内容编写测试。
- [x] 实现纯函数盘点模块与 Vite 中间件 CLI，输出中文 Markdown 与机器 JSON。
- [x] 将只读盘点接入 Quality 工作流摘要和报告归档；保持它非阻断，不改变发布准入状态。
- [x] 更新中文 README、路线图、需求追踪、变更记录和测试证据。
- [x] 完成定向与全量测试、生产构建、质量门禁、工作流语法检查及本地提交。

## 验收边界

- 报告必须区分源活动数、兼容活动数、精确去重后数量和素材缺口。
- 报告不得包含题干、选项、答案、提示或讲解；Markdown 明示未完成题目审核。
- 当前仓库盘点报告与 V1.0 正式单元数 254 一致；源活动 ID 冲突和课程目录问题需显式列出。
- 即使课程目录或素材存在缺口，盘点本身也不作为题目质量门禁；无法载入数据时必须非成功退出并覆盖旧报告。
