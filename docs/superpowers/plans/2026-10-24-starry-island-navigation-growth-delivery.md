# 星岛学园导航与成长改版实施计划索引

状态：规格复核完成，导航、首页、成长中心、设置/备份恢复及闯关结果音效已在当前分支实施。全量单测、生产构建和 `git diff --check` 已通过；Playwright E2E 因 macOS Chromium `bootstrap_check_in` 权限错误与 `SIGTRAP` 未能启动，仍待可用浏览器环境复验。当前分支尚未推送。

## 复核修正

设计规格 review 补充并明确了两项实现约束：

1. 现有完整 `pilotManifest` 约 560 KB。首页和成长概览不得将其作为摘要依赖；采用仅含成长需要字段的组级索引，并通过测试对照正式组清单，避免索引和题库内容漂移。
2. `data-sound-silent` 只屏蔽 AppFrame 的交互点击音，不影响 `SoundProvider.playCue`。闯关保留该标记以避免点击音叠加，由答题器在答案/成绩持久化后主动播放现有结果音。

复核未发现需要重新裁定的产品行为冲突。无障碍焦点时机、课程学习历史迁移、旧路径兼容、课程起点替换说明、挑战存储失败降级和两域进度隔离均已纳入计划验收。

- 本次已完成 UI 与路由实现；当前全量单测为 174 个文件、1216 项通过，生产构建和 `git diff --check` 通过。

- 本次没有修改课程题目；正式发布仍需按既定流程通过题库质量门禁、课程学习/闯关端到端回归及必要的教学内容审核。
